# Photo Compressor (Local Web App)

Локальный “сайт” на **Python + Flask**, который позволяет сжимать фотографии **пакетом** через браузер:

- ✅ Выбор **всех или части** файлов
- ✅ **Drag & Drop**
- ✅ Таблица размеров **ДО / ПОСЛЕ**
- ✅ Регулировка **качества** ползунком
- ✅ **Авто-подбор лучшего качества** под целевой размер
- ✅ Конвертация в **WebP** или **JPEG**
- ✅ Скачивание результата **ZIP-архивом** + отдельные файлы

> Приложение работает локально на вашем компьютере (без интернета).

---

## 1) Требования

- Python 3.9+ (желательно)
- pip

---

## 2) Установка

Откройте терминал в папке проекта и выполните:

```bash
pip install flask pillow
```

---

## 3) Структура проекта

Убедитесь, что файлы расположены так:

```
photo_compressor_web/
├─ app.py
├─ jobs/                (создастся автоматически при первом запуске)
├─ templates/
│  └─ index.html
└─ static/
   ├─ styles.css
   └─ app.js
```

---

## 4) Запуск

В папке проекта:

```bash
python app.py
```

После запуска откройте в браузере:

```
http://127.0.0.1:5000
```

---

## 5) Как пользоваться

1. Перетащите фото в область Drag & Drop **или** нажмите “Выбрать файлы”.
2. Настройте параметры:
   - **Формат:** WebP (рекоменд.) или JPEG
   - **Авто-подбор:** включено по умолчанию
   - **Целевой размер (%):** например 40% от исходного
   - **Мин. качество (в авто):** ниже этого авто не опустится
   - **Ограничение размера (px):** уменьшает очень большие фото
3. Нажмите **“Сжать”**
4. Скачайте:
   - **ZIP** со всеми файлами
   - или отдельные файлы в таблице

---

## 6) Пояснение параметров

### Авто-подбор лучшего качества
Если включён, приложение подбирает **максимально возможное качество**, которое укладывается в цель:

- Цель = `исходный_размер × (target_percent / 100)`
- Авто подбирает качество бинарным поиском
- Но не опускается ниже **Min quality**

### Quality
Используется **только если авто выключено**.

### Max dimension
Ограничивает длинную сторону изображения (например 2500 px).  
Это часто даёт **самую большую экономию** без заметной потери качества, особенно для фото с телефонов.

## 7) Поддерживаемые форматы входа

- WebP
- BMP
- TIFF / TIF

Выходные форматы:
- WebP или JPEG

## 8) Где лежат результаты

После сжатия создаётся папка `jobs/<job_id>/out/`, где лежат готовые файлы.  
ZIP формируется “на лету”, но файлы остаются на диске, пока вы их не удалите вручную.

---

## 9) Частые вопросы

### Почему WebP рекомендуется?
WebP чаще даёт меньший размер при хорошем качестве по сравнению с JPEG.

### PNG с прозрачностью
Если выбран JPEG — прозрачность будет сплющена на белый фон (иначе JPEG не умеет альфа-канал).  
Если выбран WebP — прозрачность сохраняется.

### Можно ли сделать .exe?
